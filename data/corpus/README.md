# data/corpus

Textes sources de l'assistant réglementaire (RAG) : LBA, OBA-FINMA, CDB, accord FATCA CH-US,
recommandations du GAFI et textes sur les sanctions.

Règle : uniquement des documents publics et officiels. Aucune donnée client réelle.
Chaque document doit permettre de citer sa source (titre, version, date, URL d'origine).
